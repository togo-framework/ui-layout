# @togo-framework/ui-layout

App shell/layout primitives from the togo UI kit: `AppSidebar`, `AppPageShell`,
`AppLayout`, `AdminLayout`, `ViewToggle`, `RouteProgress`.

```bash
npm install @togo-framework/ui-layout
```

```tsx
import { AppLayout, AppSidebar } from "@togo-framework/ui-layout";
```

Requires `@togo-framework/ui-core` (installed automatically as a dependency).
Part of the split of the former monolithic `@togo-framework/ui` package.
